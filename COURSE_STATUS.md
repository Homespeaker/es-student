RC-цепь и микрофон не были доступны при реализации. Файлы измерений и записи

## Сборка и тесты

Для Pico SDK и picotool нужна версия 2.3.0. В текущем окружении:
`PICO_SDK_PATH=C:\Repositories\pico\pico-sdk`,
`PICOTOOL_DIR=C:\Repositories\pico\picotool`.

```powershell
python tools/build_all.py
python tests/run_native.py
```

Каждый проект независим. В его `build/` создаются `.elf`, `.bin`, `.uf2`, карта
памяти и журналы сборки. Общий отчёт записывается в `build/build-results.json`.
Для `run_native.py` нужен обычный GCC для компьютера, не Arm-компилятор.
Тесты выполняют настоящие модули C с управляемыми часами и входами:
протокол, граничные размеры команды, дребезг, удержание кнопки, расписание,
расчёт π и двоичные кадры. Эти тесты не заменяют аппаратные измерения.

Отключение секундомеров проверяется отдельной сборкой:

```powershell
cmake -S 231-firmware-template -B 231-firmware-template/build-no-profile -G Ninja -DPROFILING_ENABLED=OFF -Dpicotool_DIR=C:/Repositories/pico/picotool
cmake --build 231-firmware-template/build-no-profile --parallel 12
```

## Прогоны на устройстве

```powershell
python -m venv build/venv
build/venv/Scripts/python -m pip install -r requirements.txt
```

Скрипты запускаются **из папки своего проекта**, чтобы логи попали рядом
с прошивкой. Сначала запишите его `.uf2` через BOOTSEL. Одновременно порт
может использовать только одна программа.

Для занятий 1.2–2.3 нужна кнопка GP15–GND; в `239-two-buttons` вторая кнопка
подключена GP16–GND. Входы подтянуты к 3,3 В программно. Короткое нажатие
первой кнопки определяется при отпускании; удержание от секунды даёт только
событие долгого нажатия. Вторая кнопка работает независимо.

Для АЦП используется GP26, допустимое напряжение 0–3,3 В. В опыте с RC:
GP22 → резистор → GP26, конденсатор между GP26 и GND. Номиналы задаются
параметрами скрипта:

```powershell
../build/venv/Scripts/python get_telemetry.py --seconds 10 --period 100
../build/venv/Scripts/python rc.py --r 10 --c 100
```

Для испытательной мелодии снимите RC-цепь и соедините GP20 с GP26.
Для голоса снимите перемычку и подключите MAX9814: Vdd → 3V3,
GND → GND, Out → GP26, Gain → Vdd.

```powershell
../build/venv/Scripts/python rec_audio.py --seconds 5
../build/venv/Scripts/python rec_audio.py --melody --wav melody.wav
../build/venv/Scripts/python rec_audio.py --seconds 3 --wav recording.wav
../build/venv/Scripts/python rec_audio.py --seconds 3 --bits 8 --wav recording-8bit.wav
```

Логи курса связывают результаты с USB-серийным номером реальной платы.
Пока эти прогоны не выполнены, соответствующие проверки GitHub Actions
ожидаемо сообщают об отсутствующих данных. Примеры из учебника и данные
модульных тестов не выдаются за результаты измерений.

## Ответы по архитектуре

Перенос светодиода и изменение электрического уровня кнопки затрагивают
`platform/platform.c`. Действие кнопки задаёт `main.c` через callback.
Новая команда добавляется в `logic/api/api-callbacks.c`. Новая задача получает
собственный модуль, добавляется в библиотеку `logic` и связывается в `main.c`.
Общие библиотеки не знают о командах прибора, а задачи не подключают друг друга.

Таймер в целых микросекундах не даёт ровно 44 100 Гц: при 23 мкс получается
около 43 478 Гц, плюс задержки обработки прерываний. В рекордере шаг задаёт
делитель АЦП, а данные переносит DMA. Две области памяти позволяют передавать
готовый кадр, пока следующий заполняется. При отставании увеличивается счётчик
переполнений и пропускается испорченный кадр; потерю видно по номеру кадра.
