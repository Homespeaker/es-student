# es-student
Работаем с ant-lab, спутник делать мана

Практические проекты занятий 1.1–3.2: [состав и состояние проверки](COURSE_STATUS.md).
Сборка всех прошивок: `python tools/build_all.py`.
Проверка логики на компьютере: `python tests/run_native.py`.
